# Additional assessment activities

The quiz builder includes an Additional button above its question list. It opens a compact activity catalogue; selecting an activity adds an editable question and closes the catalogue. The existing main question picker keeps the common types. New assessment activities do not use external providers.

Activities: crossword, sentence builder, diagram labelling, category sorting, image/map hotspot, teacher audio question, student spoken answer, drawing/annotation, number line, coordinate plotting, mistake correction, memory pairs, reading/source response.

Answers are validated and saved with normal Classroom submissions. Answer keys and marking guidance are omitted from student assignment payloads. Objective activities suggest automatic marks; spoken answers, drawings and open written responses require teacher review. Returning work never transfers scores to the MIS; the existing explicit selective transfer remains required.

Audio and drawing uploads use the existing 1 MB per-file limit. Microphone recording requires a supported browser and the student's explicit permission; upload is available as an alternative. Keyboard/dropdown/coordinate inputs accompany pointer-based activities. Crosswords can also be answered through clue input fields.

The hosted demo continues to store test work in the current browser. No shared backend or billing changes were made.

Validation: 220 passing tests and syntax checks. Browser test created a four-question assessment, completed/saved/submitted it as student 100837, and verified 4 automatic points in teacher review without MIS transfer.
