# Integrated MIS test fixture — 31 October 2026

This release connects the full Model 1 demonstration timetable to the MIS. The public build is isolated at `/wist-mis-testing/`; `/wist-mis/` and `/wist-timetabling/` remain separate releases. The integrated build uses separate browser database, preferences and planning-storage names.

The independently validated revision 2 fixture has 2,017 lesson cards, including 51 PE doubles (2,068 teaching-period rows), 51 forms, 1,000 pupils, 80 teachers and 81 rooms. All compulsory pupil periods through Year 11 are covered with no teacher, room or student clashes. Years 10/11 retain nine parallel four-period option blocks, PE double, assembly and PSHE. Only Years 12/13 have study frees. Registration is additional to the forty-period cycle.

Three fictional test teachers (Mila Reed, Theo Adams and Rowan Hayes) and two additional fictional sports spaces make the demonstration feasible. All use the existing fictional test password. They are demo resources, not an assertion about actual WIST staffing or facilities. Stable pupil IDs and canonical teaching-set memberships are retained. Planning-only option groups become actual MIS courses with their own exact rosters; an older source course ID is never reused to imply different membership.

Revision 2 adds seventeen fictional primary specialists: Russian (3), Uzbek Language (2), French (2), Computing (2), Music (3), Art (1), Library (1), PE (3). Every non-PE teacher has one usual classroom or specialist room. Core teachers retain their form classrooms; pupils attend the specialists' rooms. PE uses shared sports venues; secondary PE/PSHE teachers have separate classroom bases for PSHE. Unused old specialist rooms are removed from the fixture. This is an illustrative resource plan rather than a statement of the school's actual facilities.

Primary Years 1-6 have English 8, Mathematics 8, Science 5, Humanities 2 and PSHE 2 periods with their core teacher. Specialist lessons are Russian 3, Uzbek Language 2, French 2, Computing 2, Music 2, Art 1, Library 1 and PE 2. Early years retain an aggregate developmental curriculum with Russian, Uzbek, music, library and PE specialists; Reception also has French and computing. These totals are explicitly demonstration assumptions, not verified weekly hours from the source PDF.

Group labels follow the current homeroom entries in the user's Classes.pdf rather than older unscheduled subject entries. Years 5/6 are Falcons/Huskies/Owls/Sharks and Eagles/Foxes/Osprey/Wolves. Stable groups FS1 A-D retain Bunnies/Kittens/Giraffes/Zebras names; FS2 A-C use Reception Macaws/Peacocks/Penguins. The fourth Reception group is explicitly Reception Robins (demo), preserving the requested four-group population. All group and pupil IDs remain unchanged. The latest fixture uses revision 2 storage names; revision 1 browser data is retained under its previous names, not deleted. The older colleague MIS remains unchanged.

The active fixture is installed before API stores initialize. It drives date-specific teacher homepages, Directory staff/student schedules, attendance overview, lesson registers, teacher ownership and grade/report course metadata. Double lessons generate two period registers. Registers begin unmarked; saved attendance carries forward by student ID. Every active secondary subject course receives five fictional assessments with one in twenty result cells missed. Browser records persist on that browser and are not synchronized across colleagues. The active test week starts Monday 2 November 2026.

Planning edits remain drafts and do not silently change the active MIS week. This release activates the reviewed static fixture at build time. It does not add runtime publication of arbitrary manager drafts.

The school-wide test sign-in is now `admin` with the existing shared fictional test password. `report.reviewer` remains a compatible alias, retaining the same saved reviewer identity and history. This workspace provides timetable management, whole-school attendance oversight, Directory access, grade inspection and report approval/issue actions. Teacher accounts remain the route for entering their allocated lesson marks and attendance; this change does not add teacher impersonation, user management or a production authorization backend. The login picker and account download include the administrator. All 162 tests pass.
