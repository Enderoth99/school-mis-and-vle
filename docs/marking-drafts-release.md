# Private marking drafts — 0.33.0

Assignment and quiz reviews have a Save marking draft action, separate from returning feedback. It saves an optional overall mark, private feedback, partial quiz awards/answer comments and partial rubric selections. Incomplete required marks can be saved. Reopening restores the current teacher's saved content; the student submission, returned feedback and MIS records remain unchanged.

Drafts are scoped to teacher, assignment and student. Students and parents cannot save or retrieve them; other staff, including administrators, do not receive someone else's draft. Teacher backups contain only that teacher's scoped drafts. Draft saves validate allocation, assigned students, mark bounds, rubric levels, question IDs and feedback lengths. Assignment, submission and draft revisions reject stale saves. A withdrawn/resubmitted response makes an older draft stale, so its marks are not loaded into the review. Returning feedback clears the returning teacher's draft, and rejects an outdated draft revision when the form supplies it. Legacy return clients remain compatible.

Validation: 316 automated tests and syntax checks pass. Tests cover private visibility, no change to submissions/student updates/MIS, partial quiz/rubric marking, concurrent saves and returns, student resubmission, staff ownership, invalid data and the HTTP endpoint. Browser QA saved feedback with a blank required mark, reloaded and recovered it with zero grades returned, and saved quiz notes/awards separately from returning. The integrated demo retains its existing browser-local records and database namespace.
