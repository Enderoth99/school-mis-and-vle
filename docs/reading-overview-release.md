# Class reading overview — 0.39.0

Teachers open Materials → Class reading overview to see current-version confirmation totals for every enrolled student. Filters cover outstanding reading, all students, fully confirmed reading and materials updated since a student's confirmation. A collapsed By material table links to existing detailed reports. The table has a bounded scroll area.

Only allocated staff and administrators may retrieve the overview. Archived and other-class materials are excluded. No assignments, grades or notifications are changed. Confirmations remain self-reported, not evidence of learning. The free demo remains browser-local with the existing storage namespace.
